# HA examples

- `run_api.py` is a compact public-API example.
- `tutorial_api.py` reproduces the detailed multi-volume MgO documentation
  tutorial, including HDF5 output, a deterministic report, and selected plots.

Both scripts accept a normalized phonon YAML input. The curated MgO input under
`examples/qha/crystal-qha/mgo_b3lyp.yaml` is used by the documentation.
